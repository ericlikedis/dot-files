# dot-files

1) `.bashrc` - from what i know, this is just a default configuration 

2) `.zshrc` - this is my preferred shell which has all the plugins and aliases set

3) `fetchtools.sh` - downloads all dependencies my `.zshrc` needs to run properly. 
    - `micro` installs micro text editor
    - `zsh` install zsh
        plugins: 
        - `zsh-autocomplete.plugin.zsh` - installs auto complete plugin
        - `zsh-syntax-highlighting.plugin.zsh` - installs syntax highlighting plugin
    - `screenfetch` installs screenfetch, i have an alias that sets it to run as `fetch`
    -`lambda-gitster` - installs lambda-gister zsh theme
